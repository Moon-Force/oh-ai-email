# Brand · Icons

## 主图标（推荐）

**信封 + Lumen 蓝珠**

| 文件 | 用途 |
|------|------|
| [`icon-primary.jpg`](./icon-primary.jpg) | **正式主图标**（应用商店 / README / 桌面） |
| [`icon.svg`](./icon.svg) | 矢量稿，托盘、favicon、可缩放 UI |
| [`../app-icon.jpg`](../app-icon.jpg) | 快捷入口副本 |

**概念**

- 圆角方底板：雾蓝哑光，安静
- 信封造型：清晰可识别，避免廉价 3D 卡通
- 中央 **Lumen 蓝珠** `#2F6BFF`：品牌主色 / AI 焦点色（与 MUI `primary.main` 对齐）
- 无文字、无角标、无神经网络杂讯

小尺寸仍可读：外形是「信」，记忆点是「蓝光」。
