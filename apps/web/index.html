常见问题解答 (FAQ)

关于隐私、协议支持与使用方式的一切

这和自建邮件服务器或第三方中转有何不同？ ▼
oh-ai-email 只做纯客户端，绝不自建邮件服务器，也不做中间服务器代收代发。你的邮件数据直接通过标准 TLS 加密的 IMAP/SMTP 协议与 QQ邮箱、163网易、Gmail、Outlook 或企业邮服务商通信。
我的邮箱密码与 AI Key 安全吗？ ▼
绝对安全。密码和密钥仅保存在你本机的操作系统安全存储库中（Windows safeStorage / macOS Keychain）。使用本地 Ollama 模式时，邮件内容连云端都不会发送，100% 在本地显卡/CPU 计算。
AI 会不会在我不知情的情况下自动发送邮件？ ▼
绝不。 产品的核心原则是「人机协同（Human-in-the-loop）」。AI 生成的回复只会作为可编辑的草稿插入编辑器中，最终的发信按钮永远必须由用户手动点击。
如何配置本地 Ollama 离线运行？ ▼
在本地安装 Ollama 并运行模型（例如 ollama run qwen2.5:7b 或 ollama run deepseek-r1:8b），打开客户端「设置中心」->「AI 设置」，选择「Ollama 本地模式」即可一键自动识别模型。
