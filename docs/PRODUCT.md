# 产品说明

## 1. 一句话

**oh-ai-email**：开源、桌面优先的 AI 邮箱客户端，气质接近 [Spark](https://sparkmailapp.com/)，帮用户整理收件箱并用 AI 写得更快——**不自建邮件服务器**，只连接用户已有邮箱。

## 2. 对标

| 产品       | 关系                                             |
| ---------- | ------------------------------------------------ |
| **Spark**  | 主对标：友好 UI、智能收件箱、AI 写作/摘要/改语气 |
| Superhuman | 仅参考部分效率点（快捷键作增强，不绑架交互）     |

### Spark 气质（要）

- 好上手，鼠标/触控板优先，快捷键为增强
- 智能整理（重要 / 其他 / 订阅等）
- AI：草稿、改语气、扩写缩写、翻译、线程摘要
- 稍后处理、固定、静音等「管收件箱」能力
- 多账号（一期可先单账号，结构预留多账号）

### Superhuman 气质（刻意弱化）

- 不把「全键盘流」当第一体验
- 不做已读回执等强协作追踪为核心卖点

## 3. 已锁定约束

| 决策点      | 选择                   | 含义                                                                        |
| ----------- | ---------------------- | --------------------------------------------------------------------------- |
| 鸿蒙 / 移动 | **二期**               | 一期不阻塞桌面交付                                                          |
| 端优先级    | **桌面**               | Win / macOS / Linux 先                                                      |
| AI          | **混合**               | 云端默认；本地 Ollama 可选                                                  |
| 产品形态    | **客户端**             | IMAP/SMTP（及后续 OAuth），不自建邮服                                       |
| 技术偏好    | 无强偏好               | 按桌面+性能选型                                                             |
| 视觉        | **MUI Material UI**    | `@mui/material` 组件与主题；明暗模式；AI 助手面板（不自动发送） |

## 4. 用户与场景

**目标用户**

- 每天处理大量邮件的个人 / 知识工作者
- 希望 AI 帮忙摘要、起草，但不想完全把邮件托管给闭源黑盒（开源 + 可选本地模型）

**核心场景**

1. 打开应用 → 快速看到「该处理」的邮件
2. 长线程一键摘要
3. AI 生成回复 → 人改 → 发送
4. 订阅/通知类邮件降噪，不淹没主收件箱
5. 敏感场景切换「仅本地 AI」

## 5. 范围边界

### 做

- 第三方邮件客户端（Gmail / Outlook / 163 / QQ / 企业邮等，协议可达即可）
- 本地缓存、离线读已同步邮件
- 云端 AI + 本地 AI 路由
- 开源发布（仓库：`oh-ai-email`）

### 不做（明确砍掉）

- 自建 SMTP/IMAP 邮件服务、域名邮箱托管
- 一期 iOS / Android / 鸿蒙上架
- 一期完整日历/联系人套件（可预留接口）
- 企业级合规套件、完整 MDM（后续再议）

## 6. 分期产品目标

### 一期（Desktop MVP）

「能当日常邮箱用 + 有明显 AI 增益」

- 添加账号、同步、读信、回信、发送
- 本地缓存
- 分箱（至少：重要 / 其他）
- AI：摘要、草稿回复、改语气（云端）
- 设置：云端 / 本地 Ollama 开关
- 基础快捷键（可选增强，非必会）

### 二期

- iOS / Android（及鸿蒙）
- Gmail / Microsoft OAuth 完善
- 更强智能分箱、稍后处理、固定、静音
- 多账号体验打磨、推送策略
- 日历轻集成（可选）

### 三期（探索）

- JMAP 优先路径
- Agent 级自动化（用户确认后的批量归档/标签）
- 插件或 MCP 扩展

## 7. 成功标准（一期）

| 指标   | 标准                                                       |
| ------ | ---------------------------------------------------------- |
| 可用性 | 用真实 IMAP 账号可完成收/读/回/发全流程                    |
| 性能感 | 列表滚动与打开邮件无明显卡顿（本地库优先）                 |
| AI     | 摘要与草稿在云端模式下可用；本地模式在已装 Ollama 时可切换 |
| 体验   | 新用户 10 分钟内完成「加账号 → 看到信 → AI 摘要一条」      |
| 工程   | Win / macOS / Linux 可构建安装包（至少 CI 覆盖其中两端）   |
